# YTD reconciliation, ten randomly chosen banks

Seed 20260921. Drawn from the 4717 primary-sample banks with all twelve window quarters present.

`NTRERESQ` is a quarterly field and is used as reported. `NTCONOTH` has no quarterly field, so it is year-to-date and is differenced within each calendar year (Q1 = Q1ytd; Q2 = Q2ytd − Q1ytd; and so on). YTD values are never summed across quarters.
